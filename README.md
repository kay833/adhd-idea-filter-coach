# ADHD Idea Filter Coach

A five-question interview that turns "I have an idea" into one honest verdict: **build it, kill it, park it, delegate it, or test it small first.**

Built for brains that generate ideas faster than they can evaluate them. It doesn't get you excited about the idea — you're already there. It gets you an answer you can trust.

By [Kay Phillips](https://thekayphillips.substack.com), from [The Grit & Grace Letters](https://thekayphillips.substack.com).

## Install it

Tell your AI:

> Install the skill at https://raw.githubusercontent.com/kay833/adhd-idea-filter-coach/main/SKILL.md and use it to run me through my idea.

Works with Claude, ChatGPT, or any AI that can fetch a URL and follow instructions.

## What it does

Five questions, one at a time, adapted to how much detail you need:

1. **Timing** — is now actually the right window?
2. **Capacity** — do you really have what this needs this month?
3. **Strategic fit** — does this serve what you're building, or compete with it?
4. **Cost and expected value** — what's this actually going to take, and return?
5. **What a yes displaces** — what loses your attention if you say yes?

Then one clear verdict, defended in your own words, not a vague maybe.
